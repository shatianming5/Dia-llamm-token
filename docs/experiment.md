# Experiments

## Summary

This file is the runnable experiment ledger (baseline-first) and the single source of truth for:

- what to run (`E####` list + commands),
- what metrics/artifacts to save (contracts),
- and what proves what (`C####` links back to `docs/plan.md`).

Baseline-first rule (gate): before adding any new runnable experiment, the baseline must be passing:

- `python -m voxtoken.runner.smoke --out artifacts/smoke`
- `python -m voxtoken.runner.unified_eval --in artifacts/smoke/run.json --out artifacts/eval`

Run artifacts (audit trail):

- `.rd_queue/logs/`: stdout/stderr logs per job
- `.rd_queue/results/`: JSON summaries per job (command, exit_code, timestamps, log_path, ...)
- `.rd_queue/queue.json`: the queue file used by the runner
